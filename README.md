# Прогрессии — интерактивные модели

Набор из 9 интерактивных HTML-моделей для изучения арифметической и геометрической прогрессий на уроках математики.

**🔗 [math.oipav.ru](https://math.oipav.ru)**

---

## Что это

Каждая модель — отдельный HTML-файл без внешних зависимостей. Открывается в браузере, работает офлайн. Визуализирует конкретную учебную задачу: анимация показывает механику процесса, слайдеры позволяют менять параметры, формулы обновляются в реальном времени.

Сценарий использования: учитель выводит на проектор, запускает анимацию, разбирает задачу вместе с классом.

## Интерфейс

- **Тёмная тема** — оптимизировано под проектор, светлая тема доступна по кнопке
- **2-колоночный layout** — слева анимация/визуализация, справа формулы с живой подстановкой
- **Кнопки управления** — Пуск / Пауза / Сброс, регулировка скорости (×0.5 / ×1 / ×2)
- **Слайдеры** — интерактивное изменение параметров
- **Начальное состояние** — при открытии модель стоит на паузе в начале: параметры видны, ответ не раскрыт

---

## Технически

- Каждый файл — полностью автономный HTML + CSS + JS, без npm, без фреймворков
- Анимация через `requestAnimationFrame`, рендеринг на `<canvas>`
- Canvas масштабируется под `devicePixelRatio` — чёткий рисунок на Retina-экранах
- Адаптируется под размер окна через `resize`-обработчик
