# Прогрессии — интерактивные модели

19 интерактивных моделей для уроков математики: задачи на арифметическую и геометрическую прогрессии из ОГЭ (9 класс) и ЕГЭ базового уровня (11 класс), а также четыре замечательные последовательности.

## Как устроена модель

Каждая страница модели одинакова по устройству:

- **Сцена** — анимация процесса из задачи. Внизу плеер: пуск/пауза, шаг вперёд/назад, перемотка по таймлайну, скорость ½×–2×.
- **Табло** поверх сцены — живые величины (секунда, пройденный путь, масса…). Итоговый ответ табло не раскрывает раньше времени.
- **Условие** — текст задачи; числа в нём подсвечены и меняются вместе с параметрами.
- **Параметры** — слайдеры с кнопками ±, «Как в задаче» (вернуть исходные числа) и «Другие числа» (случайный корректный вариант).
- **Решение** — пошагово, с формулами. Результаты размыты, пока их не откроют кнопкой «Показать» или пока анимация не дойдёт до конца.
- **Члены последовательности** — синхронизированы с анимацией.
- **О модели** — теория и история (выдвижная панель).

Клавиши: `Пробел` — пуск/пауза, `←` `→` — шаг, `R` — сначала, `F` — во весь экран, `T` — тема, `I` — о модели.

Светлая и тёмная темы, адаптивная вёрстка (проектор, ноутбук, телефон), работа без интернета.

## Технически

Без сборки и зависимостей: страницы открываются прямо из файловой системы или раздаются любым статическим сервером.

```
index.html          каталог моделей
<модель>.html       описание одной модели: параметры, формулы, решение, рисунок
assets/lab.js       движок: плеер, панели, мини-вёрстка формул, утилиты рисования
assets/lab.css      дизайн-система: темы, акцентные палитры, раскладка
assets/catalog.js   список моделей для главной и навигации между ними
```

Модель описывается одним вызовом `Lab.model({...})`: параметры, функция `compute` с математикой, текст условия, шаги решения и функция `draw` для холста. Всё остальное — плеер, панели, темы, клавиатура, адаптивность — общее.

Формулы пишутся упрощённой записью: `F('S_n = \\frac{a_1 + a_n}{2}*n')` превращается в аккуратную формулу с индексами и дробью.

Для отладки модель доступна в консоли как `labModel` (`labModel.setT(3)`, `labModel.set('N', 10)`).
