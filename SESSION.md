# Интерактивные модели — Арифметическая прогрессия

## Проект
Набор интерактивных HTML-моделей для преподавания темы «Арифметическая прогрессия» на уроках математики. Каждая модель — самодостаточный HTML-файл (без зависимостей), визуализирующий конкретную задачу с анимацией, слайдерами параметров и живой подстановкой в формулы.

## Файлы

| Файл | Задача | Параметры |
|---|---|---|
| `index.html` | Главная страница — список всех задач с текстами | — |
| `stone.html` | Камень падает в ущелье (9 м первая секунда, +10 м каждая следующая) | a₁, d, N |
| `tables.html` | Столики в кафе сдвигают в ряд (4 места, +2 за каждый следующий) | N |
| `amphitheater.html` | Амфитеатр: 14 рядов, a₅=27, a₈=36, найти последний ряд | Рядов, a₅, a₈ |
| `train.html` | Поезд от станции: 0.2 м первая секунда, +0.4 м каждая следующая | a₁, d, N |

## Архитектура
- Каждый файл — standalone HTML + CSS + JS (Canvas для визуализации)
- Тёмная тема (dark UI), оптимизировано для проектора — крупные формулы, без скроллинга
- 2-колоночный layout: слева — визуализация/анимация, справа — формулы
- Слайдеры для интерактивного изменения параметров
- Анимация через `requestAnimationFrame`, кнопки Пуск/Пауза/Сброс, регулировка скорости
- Canvas рендеринг с учётом `devicePixelRatio` для чёткости на Retina

## Педагогические задачи
1. Визуально показать механику арифметической прогрессии
2. Дать ученикам возможность экспериментировать с параметрами
3. Показать, когда ручной подсчёт работает (малые N) vs когда нужна формула (большие N)
4. Отображать формулы с живой подстановкой числовых значений
5. Сравнение «перебор» vs «формула» в нижней панели

## Ключевые решения
- Отказ от GeoGebra из-за бага с implicit multiplication (однобуквенные переменные парсятся как произведение)
- Убраны столбчатые диаграммы из всех моделей — не несут достаточно смысловой нагрузки для проектора
- Слайдеры a₁ и d в `train.html` хранятся как ×10 (целые числа), отображаются как десятичные дроби
